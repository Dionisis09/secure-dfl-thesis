# Historical v4 evidence

The receipts in this folder were generated for commit
`14f5a807a2cbca2c9cb35366d15fbc67cc3bb7dd` (functional tests plus two confirmed
active attacks). They are preserved as historical evidence, not silently
relabelled as v5 results. Their source hashes refer to that snapshot.

The v4 BFV Node path is now **disabled by default**. Its attack reproduction
script explicitly opts into the unsafe historical implementation. Current
verified-HE implementation and new measurements live in `secure_protocol_v5`.
