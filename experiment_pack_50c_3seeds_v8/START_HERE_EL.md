# Έτοιμο πακέτο GPU — 50 clients, seeds 1/2/3

**Αντικαταστάθηκε στις 7/11 από το `experiment_pack_50c_3seeds_v8_1`.**
Ο παρών φάκελος διατηρεί το αρχικό frozen snapshot. Το calibration ανέδειξε
πολύ υψηλό κόστος και σφάλμα αρχειοθέτησης που διορθώθηκε. Δες τα
`results/calibration_50c_20261107/README.md` και τις οδηγίες της νέας έκδοσης.
Οι οδηγίες που ακολουθούν καταγράφουν την αρχική παράδοση.

Κατάσταση: **προετοιμασμένο, χωρίς εκκίνηση της επιστημονικής καμπάνιας**.
Η RTX 4090 του server λειτουργεί ξανά μετά την επανεκκίνηση.

Το πακέτο καλύπτει MLP και CNN με συγκρίσιμο αριθμό παραμέτρων, MNIST,
Fashion-MNIST και CIFAR-10, ring/full/Caveman/Barabási–Albert, IID/shards και
Dirichlet α=0,1/0,5/1,0. Όλα τα jobs χρησιμοποιούν 50 clients.
Τα επιστημονικά runs έχουν seeds 1,2,3. Τα seeds 0 των ελέγχων και 7 του
tuning διαχωρίζονται και δεν υπολογίζονται ως επαναλήψεις των αποτελεσμάτων.

Υπάρχουν 3.110 μοναδικά προγραμματισμένα jobs: 2.160 κύρια, 360 επιπλέον
sensitivity, 540 μικρά network demos και 50 έλεγχοι/δοκιμές/tuning. Η βασική
εκπαίδευση έχει 60 γύρους, ένα τοπικό epoch και batch 128. Τα network demos
έχουν 2 γύρους και μικρό υποσύνολο δεδομένων. Το HE προστατεύει το τελικό
classifier layer με joint key και υποχρεωτικά proofs. Το pairwise masking
καλύπτει το υπόλοιπο floating model state στις αντίστοιχες μεθόδους.
Τα none και public-seed masking είναι ρητά αδύναμα ablations ως προς τους peers.

## Πού βρίσκεται

- Server: `~/secure-dfl-gpu-pack`
- Environment: `~/.venvs/secure-dfl-bench`
- Config/state: `experiment_pack_50c_3seeds_v8/`
- Έτοιμα επίσημα datasets: `data-cache/` στον server.
- Αναλυτικό πρωτόκολλο και όρια: `docs/GPU_EXPERIMENT_PACK_50C_3SEEDS.md`.
- Αποδεικτικά μικρών ελέγχων: `results/experiment_pack_20261106/`.

Το ZIP περιέχει κώδικα, frozen configs/hashes, οδηγίες και δημόσια αποδεικτικά.
Δεν περιέχει datasets, ιδιωτικά keys, κωδικούς ή trained checkpoints.
Σε νέο μηχάνημα χρειάζεται εγκατάσταση dependencies, build του native backend
και προετοιμασία των datasets σύμφωνα με τον αναλυτικό οδηγό.

## Όταν αποφασίσουμε να ξεκινήσουμε

Μέσα στο υπάρχον server workspace:

```bash
cd ~/secure-dfl-gpu-pack
bash experiment_pack_50c_3seeds_v8/start_gpu_gates.sh
```

Αυτή η **ρητή εντολή** ξεκινά μόνο τους δύο ελέγχους GPU με 50 clients.
Δεν εκκινεί ολόκληρη την καμπάνια. Έπειτα ελέγχουμε χρόνο, RAM, δίσκο και
σωστή εκτέλεση, προχωρούμε στα smoke/tuning και τέλος στα επιστημονικά runs.
Ο controller σταματά αν η συντηρητική εκτίμηση υπερβαίνει το ορισμένο budget.
Δεν έχουμε ακόμα επαληθευμένη διάρκεια για το πλήρες νέο πρωτόκολλο.

Η επανεκκίνηση επαληθεύει τα ολοκληρωμένα receipts και τα παραλείπει.
Τα checkpoints επιτρέπουν συνέχιση από ολοκληρωμένους γύρους· μια διακοπή
μέσα στην κρυπτογραφική φάση απαιτεί έλεγχο και δεν αντιμετωπίζεται με σιωπηλή
επανάληψη ή αποκρυπτογραφημένο fallback. Μόνο πλήρεις ομάδες τριών seeds
δίνουν mean/sample SD. Οι χρόνοι διαφορετικών περιβαλλόντων παραμένουν χωριστοί.

Τα παλιά αποτελέσματα, το dashboard, το Word και το PowerPoint διατηρούνται.
Τα νέα μικρά functional tests δεν είναι αποτελέσματα accuracy της διπλωματικής.
