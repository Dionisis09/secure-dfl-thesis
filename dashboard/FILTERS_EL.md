# Οδηγός φίλτρων του dashboard

Τα φίλτρα επιλέγουν αποθηκευμένα αποτελέσματα· δεν ξεκινούν πειράματα.
Το **All** αφαιρεί τον περιορισμό του συγκεκριμένου φίλτρου. Τα φίλτρα λειτουργούν μαζί.

| Φίλτρο | Τι επιλέγει / επιλογές |
| --- | --- |
| Campaign | Προέλευση runs: αρχική καμπάνια `original_20261014` ή επέκταση `extension_20261020`. Η επέκταση σχεδιάστηκε για 1.440 runs, αλλά έχουν ολοκληρωθεί τα 228 της επιλεγμένης σειράς. |
| Comparison scope | Αρχικά 402, επιλεγμένα 228 ή υπόλοιπη επέκταση σε αναβολή. Τα εκκρεμή runs δεν αποτελούν μετρήσεις απόδοσης. |
| Workflow | `validation`: συγκρίσεις με πλήρη datasets, 20 γύρους και seeds 1/2/3. `sensitivity`: επίδραση του HE ratio, seed 42. `network`: τοπικό HTTP demo 3 κόμβων, 2 γύρων, με υποσύνολα 1.500 train / 500 test. Τα workflows έχουν διαφορετικούς σκοπούς και προϋπολογισμούς. |
| Dataset | MNIST: ψηφία. Fashion-MNIST: είδη ένδυσης. CIFAR-10: έγχρωμες εικόνες αντικειμένων και ζώων. |
| Dirichlet alpha | Αφορά το split `dirichlet`. α=0,1: εντονότερη συγκέντρωση κλάσεων κατά μέσο όρο· α=0,5: ενδιάμεση· α=1,0: ηπιότερη. Η κατανομή αλλάζει και τα πλήθη δειγμάτων ανά client. |
| Split | `iid`: τυχαίος διαμοιρασμός με παρόμοιες αναλογίες κλάσεων κατά μέσο όρο. `non_iid`: δύο label-sorted shards ανά client. `dirichlet`: χωριστή πιθανοτική κατανομή κάθε κλάσης στους clients με το επιλεγμένο α. |
| Topology | `ring`: δακτύλιος, δύο γείτονες. `fully_connected`: επικοινωνία με όλους. `caveman`: δύο πυκνές κοινότητες που συνδέονται. `barabasi_albert`: preferential attachment με m=2 και άνισους βαθμούς κόμβων. |
| Clients | Πλήθος κόμβων: 5/10 στις συγκρίσεις validation, 5 στο sensitivity, 3 στα συγκεκριμένα network demos. |
| Security mode | `none`: baseline. `masking`: πρόσθετες μάσκες. `pairwise_masking`: ζευγαρωτές μάσκες που αλληλοαναιρούνται στην άθροιση. `selective_he`: CKKS στο τελευταίο layer. `adaptive_hybrid`: συνδυασμός pairwise masking και επιλεκτικής HE σε μέρος των γειτονιών. Πρόκειται για υλοποίηση πρωτοτύπου· η ίδια accuracy δεν αποδεικνύει ισοδύναμη ιδιωτικότητα. |
| Execution profile | `legacy`: αρχικός τρόπος εκτέλεσης. `cached_gpu`: cache εικόνων και λιγότερες μεταφορές μετρικών μεταξύ CPU/GPU, με ίδιες ρυθμίσεις εκπαίδευσης. Οι χρόνοι συγκρίνονται χωριστά ανά προφίλ, περιβάλλον και συνεδρία εκτέλεσης. |
| Clear all | Επαναφέρει τις προεπιλεγμένες τιμές των φίλτρων. Δεν σημαίνει υποχρεωτικά ότι κάθε φίλτρο γίνεται All. |

## Πώς περιορίζονται οι πολλές καμπύλες

Οι «74 κατηγορίες» είναι συνδυασμοί ρυθμίσεων, όχι 74 datasets ή 74 ανεξάρτητα seeds.
Για ευανάγνωστη σύγκριση ορίζουμε πρώτα το ερώτημα και κρατάμε σταθερές τις υπόλοιπες διαστάσεις.

- **Σύγκριση security modes:** Original 402 → validation → ένα dataset → 5 clients → ring → IID → Security mode All. Έτσι συγκρίνουμε τις πέντε μεθόδους στην ίδια ρύθμιση. Αν οι καμπύλες συμπίπτουν, αυτό είναι αποτέλεσμα και δεν χρειάζεται τεχνητός διαχωρισμός των τιμών.
- **Σύγκριση τοπολογιών:** validation → ένα dataset → ένα πλήθος clients → ένα split → Security mode none → Topology All. Ελέγχουμε ποια καμπάνια περιέχει τις επιθυμητές τοπολογίες. Για κοινή σύγκριση τεσσάρων τοπολογιών με IID/shards υπάρχουν αποτελέσματα CIFAR-10 από τις δύο σειρές, με ίδιο training budget.
- **Σύγκριση κατανομών:** Selected 228 → validation → CIFAR-10 → 5 ή 10 clients → Caveman ή Barabási → Security mode none → Split All και alpha All. Συγκρίνουμε IID, shards και α=0,1/0,5/1,0 σε σταθερή τοπολογία.

Κενό γράφημα μπορεί να σημαίνει ότι ο συγκεκριμένος συνδυασμός δεν έχει εκτελεστεί.
Τα α=0,1/1,0 και τα επιπλέον IID/shards των νέων τοπολογιών στην επιλεγμένη σειρά αφορούν CIFAR-10 baseline. Δεν έχουν εκτελεστεί όλοι οι συνδυασμοί όλων των φίλτρων.

## Τι σημαίνουν τα 228 runs

Η επιλεγμένη σειρά είναι **ολοκληρωμένη: 76 συνδυασμοί × 3 seeds = 228 runs**.
Δεν είναι 228 επαναλήψεις της ίδιας ρύθμισης. Χρησιμοποιεί πλήρη datasets και τις ίδιες βασικές ρυθμίσεις εκπαίδευσης.
Επιτρέπει στοχευμένη περιγραφική σύγκριση με μέσο όρο και sample SD από τρία seeds ανά συνδυασμό.
Δεν καλύπτει όλη την ευρύτερη σχεδίαση των 1.440 runs και τα τρία seeds από μόνα τους δεν τεκμηριώνουν στατιστική ισοδυναμία ή γενική υπεροχή.
Τα αρχικά 402 διατηρούνται χωριστά: συνολικά υπάρχουν **630 μοναδικά ολοκληρωμένα runs**.
